# Bezpečnosť

Našiel si chybu v zabezpečení appky „Čo to letí?“? Napíš nám cez **GitHub → Security → Report a vulnerability** (súkromné hlásenie), nie do verejných Issues.

- Testuj len na vlastnom účte/zariadení, nezahlcuj server a nesťahuj cudzie údaje.
- Odpovieme do 7 dní a po oprave ťa radi uvedieme (ak chceš).
